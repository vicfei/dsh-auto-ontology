# dsh-auto-ontology

> Auto ontology construction, natively on DeepSeek Harness: feed documents, get a typed ontology (TBox + ABox) where **every entity and relation carries its source quote.** No evidence, no assertion; unknown types flagged, never silently dropped.
>
> Implements the concept of [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology); independent community project, not affiliated.

**Status: name reserved — first release in development.**
